A practical bounded stack can reuse [Money Factory](https://github.com/wecreates/Money-factory) for queue/evidence, [last30days](https://github.com/mvanhorn/last30days-skill) for dated public research, [Ruflo](https://github.com/ruvnet/ruflo) for bounded orchestration, [Aider](https://github.com/Aider-AI/aider) for repository editing with lint/tests, [Playwright](https://github.com/microsoft/playwright) for browser acceptance evidence, and [Coolify](https://github.com/coollabsio/coolify) for optional self-hosted preview deployment.

This is a researched composition, not an installed autonomous app factory. Existing Ruflo/OpenClaw text adapters are not coding sandboxes. Aider needs a constrained runtime and a suitable model; small local models have quality limits. Coolify's [PR previews](https://coolify.io/docs/applications/deployments/preview-deployments) need host capacity, repository permissions and isolated nonproduction configuration. A unique preview URL is not private access; VPN/private access must be configured and verified separately. No Coolify install, preview deployment, paid resource creation or publication was performed. The realistic boundary is dated need evidence → one testable specification → isolated implementation/tests → private preview and evidence → owner review; no nightly throughput promise is justified yet.
